# Learning

Learning creates reviewable memory candidates from explicit user content and background review. Approval stores a memory; dismissal rejects it. Device-action and background outcomes are audited through the capability-grant model.

The Android **Controlled improvement** workflow records proposed prompt, tool, workflow, or model-routing changes. Every proposal requires distinct evidence, a measured test outcome, a benchmark comparison, and a version label. It remains `PENDING` until the owner explicitly approves or rejects it; an approved record can be rolled back with a review note. The protected server and mobile bootstrap preserve this history separately from ordinary memory.

Autonova does **not** retrain model weights, silently mutate source code, execute arbitrary shell commands, or claim intelligence improvement automatically. An approved improvement record is an auditable decision record, not an automatic deployment or a bypass of Android, provider, repository, or user-consent controls.

# Learning

Learning currently creates reviewable candidates from explicit user content and background review. Approval stores a memory; dismissal rejects it. Device-action and background outcomes are audited through the capability-grant model.

Autonova does not retrain model weights, mutate source code, or claim intelligence improvement automatically. A future Improvement Lab must require evidence, test results, benchmark comparison, explicit acceptance, versioning, and rollback before any reusable policy, workflow, or project change is accepted.

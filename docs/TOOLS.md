# Tools

The current tool registry covers public research, GitHub, code-execution proposals, document reading, image generation, HTTP requests, scoped storage, browser handoff, camera, voice, screenshots, and notifications. Tool policy is user-controlled through ASK, ALLOW, and DENY records, and consequential Android actions use explicit confirmation.

The registry is not yet a general dynamic plugin runtime. New tools must define a narrow purpose, input/output contract, permissions, network requirement, audit event, timeout, failure behavior, and test coverage before they are presented as available.

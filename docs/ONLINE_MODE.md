# Online and Optional Remote Modes

**Local Plus Internet** keeps remote-agent access off. Android browser handoff remains visible and user-confirmed; the app does not silently browse, post, or log in.

**Optional Remote Agent** requires a user-entered public HTTPS endpoint and explicit browser sign-in. It enables protected hosted chat, research, file upload, provider configuration, GitHub operations, image generation, and background synchronization. Each sensitive action remains subject to permission, provider, account, and Android platform controls.

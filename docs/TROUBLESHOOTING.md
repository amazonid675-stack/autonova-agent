# Troubleshooting

If local chat reports that no model is available, import a compatible quantized MediaPipe `.task` model in Device Capabilities. If an endpoint is rejected, use a public HTTPS endpoint and select Optional Remote Agent mode before signing in. If documents do not index, choose readable text content under 1 MB; PDF and Office parsing are not yet local capabilities.

If background review does not run, verify Android battery/network constraints and the 15-minute minimum. If GitHub operations fail, verify that the fine-grained token has only the intended repository permissions and inspect the recorded operation outcome.

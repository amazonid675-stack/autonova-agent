# Memory and Local Knowledge

Autonova distinguishes cached messages, tasks, projects, personal memories, activity, research sessions, learning candidates, and capability grants. Local memory is user-editable and can be used as context for offline local-model prompts.

The local knowledge store chunks user-selected readable text and retrieves lexical matches for a local request. It does not silently ingest sensitive data, upload text while in Local Only mode, or claim semantic/vector retrieval without an installed embedding provider.
